统一评分怎么读

分数表示“在这张表的具体语境下，这个选择有多值得优先”；A/B/C表示“对这项判断有多大把握”。二者是不同维度：高价值不等于证据等级必须是A，证据A也不意味着人人都需要。分数只在同一张表内部比较。

9–10经常优先大多数情况下是高质量选择；仍需考虑份量与总饮食。
7–8放心选择整体不错，场景合适时可常吃/常用。
5–6看场景本身并非“坏”，但更依赖份量、配料、频率或个人目标。
3–4偶尔即可营养/投入产出偏弱，或较容易带来额外糖、盐、脂肪、刺激。
1–2尽量少多数情况下没有必要作为常规选择。
分数 ≠ 证据等级：分数回答“值不值得优先”，A/B/C回答“我们有多确定”；不要用B或C机械封顶分数。
只在同表内比较：同一物品若承担不同角色，评分口径也可能不同；若重复出现，表格会明确说明口径。
先看模式，再看单品：长期饮食结构比“某一口抗炎/促炎”重要得多。
替代关系决定价值：橄榄油替代黄油有意义；在原饮食上额外加两勺油则未必。
完整食物优先：完整水果、全谷物、豆类、坚果通常比高度精制版本更稳。
加工不是原罪：酸奶、豆腐、罐头鱼也是加工食品；真正要警惕的是整体配方与高度超加工模式。
GI 不是唯一裁判：纤维、份量、蛋白脂肪搭配、食物结构都会改变餐后反应。
有效 ≠ 人人需要：维生素D、铁、B12、肌酸等都应区分“有证据”与“你是否有适应场景”。

使用护栏 · 别把“优化生活”变成新的负担

这份手册的目的，是减少重复决策成本：把高频、高影响的选择做得大体正确，然后把注意力还给生活本身。它不要求每一餐、每一次购物、每一晚睡眠都做到 9–10 分。

健康的使用方式

把高分项当默认值；偶尔选低分项不会产生罪恶感；社交、旅行和现实限制出现时能灵活调整；看一次表就能做决定，不需要反复确认。

值得降级优化的信号

为了很小的分差反复查标签、菜单或成分；规则越来越多；计划被打乱就明显焦虑；吃了“低分食物”后想用运动、禁食或其他方式补偿。

停止继续“优化”的信号

健康规则开始明显损害社交、工作或营养摄入；食物种类持续缩窄；对“纯净/不健康”产生强烈恐惧；或出现强迫运动、持续内耗等功能损害。

证据边界：“正食症 / orthorexia nervosa”目前仍缺乏统一诊断标准，也未被主要精神疾病分类系统正式确立；但近期综述与Meta分析较稳定地发现，病理性健康饮食执念与完美主义、强迫特质、饮食障碍症状和强迫运动相关。这里不是给任何人贴诊断标签，而是提醒保持灵活性。所谓“80/20”只能当一个宽松的生活启发，不是科学阈值。 S45 S46

01 · 烹饪方式 × 菜单识别速查表

分数默认假设食材相近；菜单关键词用于识别烹饪技法。实际健康度还会被油、盐、糖、酱汁、焦化程度与份量明显改变。

S1 S2
技法 / 菜单关键词评分倾向核心判断最容易误判的点证据
蒸（steamed / vapeur）10经常优先几乎不需额外油，湿热温和；尤其适合鱼、海鲜、蛋和蔬菜。高盐酱汁仍会改变整餐；“蒸”不是无条件健康。A
汆、白灼、水煮（poached / boiled / poché / bouilli）10经常优先低油、湿热，便于控制能量密度。汤底若高盐高油，不必全部喝完。A
炖、煨（stewed / simmered / mijoté）9经常优先温度相对温和，适合豆类、瘦肉与蔬菜。奶油炖、椰浆炖、重糖炖另算。A
焖、炖焖（braised / braisé）8放心选择兼顾口感与较少额外油脂。酱油、糖和收汁可能显著增加钠与能量。B
低油烤箱烤（roasted / baked / rôti / au four）8放心选择少油时是很实用的日常方法。避免明显焦黑；“焗”若大量奶酪/奶油另算。B
快炒少油（stir-fried / sauté）8放心选择时间短、蔬菜口感好；油量可控时很不错。餐馆“炒”往往比家中用油多。B
空气炸（air-fried）7.5放心选择通常比深油炸少油，是替代炸物的实用工具。仍属高温干热；裹粉超加工食物不会因此自动变健康。B
低油香煎（pan-seared / poêlé）7放心选择少油、不过焦时可纳入常规。油量与焦化程度比“煎”这个名字更重要。B
烧烤（grilled / grillé）7放心选择可少油，鱼、瘦肉和蔬菜都能做得很好。避免明显焦黑与反复炭化。B
红烧、酱烧、收汁6看场景烹调方式本身并非禁区。常见扣分来自糖、盐、肥肉和浓缩酱汁。B
烟熏（smoked / fumé）5看场景偶尔作为风味来源没有问题。烟熏加工肉与普通烟熏鱼/蔬菜要分开看；钠常偏高。B
盐腌、腌渍（cured / salé）5看场景可增加风味与保存性。重点看钠及是否属于加工肉。B
干锅（dry pot）4偶尔即可食材种类可以丰富。通常油、盐较高，蔬菜也会吸油。B
油封（confit）4偶尔即可低温、风味浓。以大量脂肪烹煮或保存，不能按“清淡低温”理解。B
挂汁、焦糖化（glazed / caramelized / glacé / caramélisé）4偶尔即可少量可增加风味。常额外带来糖、油或浓缩酱汁。B
奶油型（creamy / à la crème）4偶尔即可口感丰富。通常意味着更多饱和脂肪和能量；可要求酱汁另放。A
蜂蜜/蜜汁（honey / miel）3.5偶尔即可适合少量调味。蜂蜜依然属于游离糖来源。A
香脆（crispy / croustillant）3偶尔即可往往意味着炸、半炸或较多油。不是必然油炸，但值得进一步确认。B
天妇罗（tempura）2.5尽量少裹糊较薄，但本质仍是油炸。口感“轻”不等于能量低。A
裹粉（breaded / pané）2.5尽量少裹粉后通常煎炸。比原食材显著增加能量密度。A
挂糊油炸（battered / beignet）2尽量少厚裹糊并深炸。海鲜或蔬菜也会因此明显改分。A
深油炸（deep-fried / frit）2尽量少能量密度高，常伴随精制裹粉和较多盐。偶尔吃无需焦虑，问题主要在高频。A
明显焦黑、炭化（charred / brûlé）2尽量少高温焦化反应产物更多。不是“一口致癌”，而是没必要追求炭黑。B

02 · 烹调油与脂肪速查表

核心看脂肪酸结构与替代关系，而不是把烟点、精炼与否或“种子油”身份当成单一裁判。日常主力油优先低饱和脂肪的液体植物油。

“菜籽油”与“低芥酸菜籽油”不要完全混为一谈：能选择时，优先明确标注低芥酸的版本。
油脂评分倾向为什么注意证据
特级初榨橄榄油（extra-virgin olive oil）10经常优先单不饱和脂肪与多酚突出，适合作为主要用油。可凉拌也可正常煎炒；不必把“烟点”误当作唯一健康标准。A
低芥酸菜籽油（canola / low-erucic rapeseed oil）9.5经常优先饱和脂肪低，脂肪酸结构均衡；低芥酸是关键。中国现行 GB/T 1536-2021 将“低芥酸菜籽油”定义为芥酸≤3%；canola 通常指低芥酸类型。能选时优先明确标注“低芥酸”。A
花生油9经常优先不饱和脂肪为主，适合中高温烹调。过敏者避用；仍需控制总油量。A
大豆油9经常优先多不饱和脂肪丰富，可替代高饱和脂肪。“种子油天然促炎”并无可靠临床共识支持。A
高油酸葵花籽油 / 高油酸红花籽油9经常优先高油酸版本脂肪结构好、耐热性佳。看标签是否明确标注“高油酸（high-oleic）”。A
普通葵花籽油 / 玉米油8.5放心选择多不饱和脂肪丰富。避免反复长时间高温使用同一锅油。A
牛油果油（avocado oil）8.5放心选择单不饱和脂肪高、用途广。价格高并不代表健康优势一定高于橄榄油/低芥酸菜籽油。B
核桃油 / 亚麻籽油8放心选择α-亚麻酸（ALA）较突出。更适合凉拌或低温，开封后注意避光冷藏。B
芝麻油8放心选择不饱和脂肪为主、风味效率高。更适合少量调味而不是大量淋。B
葡萄籽油8放心选择多不饱和脂肪为主。没有必要为“抗氧化”营销支付很高溢价。B
混合植物油8放心选择若以非热带植物油为主，通常脂肪结构不错。看配料顺序与是否含部分氢化油。A
普通/未标低芥酸的菜籽油6.5看场景仍以不饱和脂肪为主，但芥酸含量可能高于低芥酸品种。若长期大量使用，优先换成明确标注低芥酸的版本更稳妥。B
黄油4偶尔即可适合提供风味。饱和脂肪较高，更适合少量而非默认主力油。A
猪油 / 其他动物油4偶尔即可有一定单不饱和脂肪，也有独特风味。总体饱和脂肪更高，不宜作为主要日常用油。A
酥油（ghee）3.5偶尔即可耐热、风味强。饱和脂肪高。A
椰子油3偶尔即可风味特殊、稳定性高。饱和脂肪很高，不优于多数液体植物油。A
棕榈油3偶尔即可工业食品中常见、稳定。饱和脂肪较高。A
部分氢化起酥油 / 含工业反式脂肪油脂1尽量少没有健康优势。尽量避免工业反式脂肪。A

03 · 主食 / 碳水速查表

优先完整谷物、豆类和高纤维淀粉来源。升糖指数（GI）只是一项参考，品种、加工、熟度、份量和同餐蛋白/脂肪都会改变实际血糖反应。

食物评分倾向为什么注意证据
燕麦（原片 / 钢切）10经常优先高纤维，β-葡聚糖证据较好，饱腹感强。即食甜味燕麦另算。A
豆类（扁豆、鹰嘴豆、黑豆、红豆等）10经常优先纤维 + 植物蛋白组合优秀。肠胃敏感者可逐步增加。A
大麦（barley）10经常优先完整谷物、可溶性纤维突出。烹煮时间较长，但营养价值很稳。A
荞麦9经常优先完整谷物替代品，纤维与矿物质不错。荞麦面要看是否大量混入精白面粉。A
藜麦（quinoa）9经常优先纤维、蛋白质与微量营养素均衡。不是神奇“超级食物”；普通全谷同样优秀。A
福尼奥米（fonio）8.5放心选择西非传统小粒谷物，部分研究显示GI偏低至中等。证据量仍小；最好按完整谷物、小份主食看待。B
小米 / 珍珠粟（mil / millet）8.5放心选择完整小米可提供纤维、矿物质，整体优于精白主食。不同品种和加工后的GI差异很大。A/B
甜玉米8放心选择整粒谷物型淀粉，水分高；实测 GI 多在低—中区间。别被“甜”字误导：甜玉米通常比糯玉米升糖更平缓。A/B
糙米8放心选择比白米保留更多纤维与微量营养素。不必为了健康强迫自己只吃糙米。A
真正全麦面包8放心选择方便、纤维较高。看配料中全麦粉是否排第一；颜色深不等于全麦。A
全麦意面8放心选择结构紧密、纤维较高，通常比精白面包更稳。酱汁和份量仍决定整餐。A
红薯（sweet potato）8放心选择钾与类胡萝卜素丰富，饱腹感好。“红薯无限吃不胖”是误区。A
普通老玉米 / 硬粒玉米7.5放心选择比精白主食多一些纤维，血糖反应通常中等。品种与加工方式差异较大。B
水煮土豆7放心选择饱腹感高、钾丰富。捣泥、长时间煮软或油炸会显著改变血糖反应和能量密度。B
水煮 / 烤大蕉（plantain）7放心选择提供钾、纤维和淀粉，可作为主食。熟度和烹调会改变血糖反应；不要把它当“无限量水果”。B
糯玉米 / 黏玉米6.5看场景仍是完整谷物，但支链淀粉比例高，很多品种实测 GI 明显高于甜玉米。不是“禁食项”；把它当主食、控制份量并与蛋白/蔬菜同餐即可。B
白米饭6看场景可以作为正常主食。纤维较低；份量与配菜比“戒米饭”更值得管理。A
库斯库斯（couscous）6看场景方便、脂肪低。通常较精制；全麦版更优。B
阿切克（attiéké，发酵木薯粒）6看场景发酵木薯主食，部分人体验GI为中等。碳水密度高、血糖负荷仍可较高，份量和配菜很重要。B
米粉 / 米线5.5看场景可以作为主食。通常精制、纤维低；汤底、油与配菜常比米粉本身更影响健康度。B
甜味格兰诺拉燕麦（granola）5看场景可含燕麦、坚果。糖、油和份量常被健康光环掩盖。B
木薯 / 木薯泥 / placali / fufu类5看场景是常见主食来源。多为高淀粉、低纤维形态，血糖反应常较高；与豆类、鱼肉、蔬菜同餐更好。B
白面包4偶尔即可方便、易消化。精制、纤维少；搭配蛋、酸奶或蔬菜可改善整餐。A
炸大蕉3.5偶尔即可仍保留部分大蕉营养。油炸增加能量密度；熟大蕉本身也较甜。B
方便面3偶尔即可快捷。精制淀粉、钠高，蔬菜与蛋白质通常不足。A
薯条2尽量少仍含土豆的一部分营养。油脂、盐和高能量密度叠加。A
甜点 / 酥皮类“主食”1.5尽量少适合作为享受型食物。精制淀粉 + 糖 + 脂肪，饱腹效率低。A

04 · 蛋白质来源速查表

综合蛋白质量、脂肪结构、加工度与常见烹调方式。鱼类、豆类/豆制品、禽肉和原味发酵乳通常优先，加工肉靠后。

刷牙后吐掉泡沫，不立即用大量清水漱口9.5经常优先让牙膏中的氟在牙面停留更久，有利于龋齿预防。漱口水若要用，可与刷牙错开时间。A
软毛牙刷 + 温和正确刷法9经常优先减少菌斑同时降低牙龈/牙体磨损风险。硬毛、用力横刷不是“更干净”。A
减少“含糖暴露频率”，甜食尽量随正餐9经常优先同样总量的糖，全天反复小口吃/喝会让牙齿经历更多次酸攻击。不只是总克数；频繁奶茶、糖果、含糖咖啡尤其值得管。A
按风险规律看牙医 / 洁牙8.5放心选择发现龋齿、牙周问题与结石。频率应按个人风险，不是人人机械半年一次。B
电动牙刷8放心选择对部分人更容易保持稳定技巧。手动牙刷同样可以有效，不必为设备焦虑。A
冲牙器 / 水牙线（water flosser）7.5放心选择牙线难操作、戴矫治器或牙龈问题时很实用。作为牙缝清洁工具之一，不替代刷牙。B
无糖口香糖（饭后短时）6看场景刺激唾液、帮助清除食物残留。不能替代刷牙；注意含糖版本。B
含氟漱口水6看场景高龋风险或特定人群可作为附加措施。不是所有低风险成人都必需。B
抗菌漱口水（如西吡氯铵CPC / 精油配方）5.5看场景可辅助减少菌斑/牙龈炎。不能替代机械清洁。B
舌苔清洁5看场景可短期改善舌苔与部分口臭。慢性口臭要寻找牙周、鼻咽等原因。B
过氧化物美白产品5看场景确有美白效果。可能造成牙敏感/牙龈刺激，按说明或牙医建议。B
美白牙膏4偶尔即可主要去除外源性色渍。不会像漂白剂那样改变牙本质颜色；注意磨蚀性。B
木炭牙膏 / 炭粉1.5尽量少缺乏明确的额外口腔健康收益。可能磨蚀且常缺少足量氟化物。C
油拔法（oil pulling）1.5尽量少证据不足。不能替代含氟刷牙、牙缝清洁或牙科治疗。C
硬毛牙刷 / 大力横刷1尽量少没有必要。增加牙龈损伤与牙体磨损风险。A

23 · 居家清洁、卫生与室内环境速查表

最有效的居家环境管理通常遵循“控制污染源 → 通风 → 控湿 → 必要过滤”的顺序；日常清洁与针对性消毒应分开理解。

S60 S61 S62
家庭清洁的目标是降低真实风险，而不是追求“无菌感”。绝大多数日常场景，先清洁就足够；有人生病或明确污染时再针对性消毒。
做法评分倾向价值注意证据
室内禁烟 / 避免二手烟与电子烟气溶胶10经常优先直接减少高影响污染源。“开窗抽烟”不能完全消除暴露。A
安装并定期测试烟雾报警器；有燃烧设备时配一氧化碳报警器10经常优先属于低成本、高后果避免型安全措施。按设备说明定期测试和更换电池/整机。A
发现漏水 / 渗水后尽快修复，并处理霉菌的“水分来源”10经常优先潮湿与持续漏水是室内霉菌问题的根源。只喷除霉剂而不修漏水，问题容易回来。A
做饭时开外排油烟机 / 排风，必要时补充通风9.5经常优先烹饪本身会产生颗粒物；外排比只循环过滤更有效。室外空气很差时要权衡开窗，优先机械外排/过滤。A
浴室洗澡后排风 / 通风，控制长期潮湿9经常优先减少湿气与霉菌生长条件。高湿环境尤其重要。A
把相对湿度控制在约30–50%，至少尽量低于60%9经常优先有助于减少霉菌、尘螨等生物污染物。过干也会不舒服；湿热地区可用空调/除湿。A
污染或过敏场景使用合适尺寸的高效颗粒空气过滤（HEPA）净化器8.5放心选择可作为源头控制和通风之外的补充。不能替代除霉、禁烟、通风等源头措施；注意CADR/房间大小。A/B
日常用清水/清洁剂擦洗，高频接触面按需清洁8.5放心选择多数家庭场景“清洁”本身已能移除大量污物与微生物。家中没人患传染病时，不必把所有表面都高强度消毒。A
湿擦除尘 + 合理吸尘8放心选择帮助减少灰尘、过敏原与部分颗粒物。过度香味清洁剂可能带来额外刺激。B
高湿时使用除湿机 / 空调控湿7.5放心选择当室内持续>60%RH时很实用。设备要定期清洁和排水。A
需要时使用漂白剂/消毒剂，并严格按标签通风和接触时间7放心选择在有人生病或明确污染时有价值。先清洁再消毒；用得更多不等于效果更好。A
普通空气清新剂 / 香氛喷雾遮味3偶尔即可能改变气味体验。通常只是遮味，不解决污染源；对敏感人群可能刺激。B/C
无明确需要时每天全屋强力消毒3偶尔即可心理上可能感觉更“干净”。CDC认为多数家庭日常清洁即可；过度消毒增加化学暴露和操作负担。A
长时间室内焚香 / 熏香来“净化空气”2尽量少气味与仪式感。燃烧会产生颗粒物，不能当空气净化手段。B
长期使用未清洁的加湿器2尽量少能提高湿度。脏水与过高湿度可能增加微生物/霉菌问题。B
有人在室内时使用臭氧发生器“消毒 / 除味”1尽量少营销常声称可净化空气。EPA明确不建议在有人空间使用；臭氧是呼吸道刺激物。A
把漂白剂与氨水、酸性清洁剂或其他清洁剂混合1尽量少没有合理家庭用途。可能释放危险气体；不要混用任何清洁/消毒化学品。A

一个健康行为它对长期结局的影响有多大是否有权威指南支持它是否真的适用于我的年龄/风险先处理戒烟、血压、疫苗、运动、睡眠等高影响动作，再优化细枝末节。

一个‘健康食品’看营养标签而非正面广告看份量与加工度它取代了什么替代对象比单品名更重要。

一个运动能否长期做是否补足有氧/抗阻缺口受伤风险与时间成本组合优于寻找‘唯一最佳运动’。
一个理财产品用途期限费用、分散、流动性最坏情况我能否承受先匹配期限，再谈收益。
一条信息/内容来源质量与原始性是否有明确目的、是否被算法牵着走这个内容让我更理解问题，还是只让我继续点下一条有目的地读、查、核，比单纯控制屏幕时长更重要。
一个食品安全问题时间 + 温度 + 生熟交叉污染能否尽快冷藏/彻底加热我是在靠气味猜，还是有温度/时间依据安全问题优先遵循硬规则，不靠“应该没事”。
一个居家环境问题先找污染源/水分源再考虑通风、控湿与过滤我是在解决源头，还是只是在遮味/消毒源头控制通常比买更多产品更有效。
